# AegisFlow AI v6 Dashboard Themes

v6 replaces the heavy dark/purple default with a calmer professional dashboard.

Available UI themes:

- Azure Clean Light — default, clean white/blue enterprise style.
- Enterprise Navy — dark sidebar with controlled blue accents.
- Minimal White — sober neutral dashboard.
- Teal Professional — light teal governance style.

The theme can be changed from the sidebar under **Dashboard style → Color theme**.
