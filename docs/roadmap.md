# Roadmap

- Local repo audit
- Live validation log
- CI/CD file generator
- Evidence report
- Optional commit/push/PR
- Optional Ollama advice

## v3
- Azure DevOps pipeline log reader
- Pipeline rerun trigger
- Work item linking
- PR comment bot
- Reviewer assignment
- Multi-repo dashboard
- Policy rules engine
- Release approval workflow

## v4
- Auto-remediation loop
- Safe patch generation
- Re-run until green
- Human approval checkpoint
- Enterprise SSO/RBAC
- Governance dashboard
